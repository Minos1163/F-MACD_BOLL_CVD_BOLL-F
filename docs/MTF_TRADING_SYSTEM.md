# 多时间框架（MTF）交易系统 V1.0

> **核心逻辑**：以 1H 级别为核心执行层，4H 级别定宏观边界与风险过滤，15m 级别抓微观动能与防范假突破。
> **适用标的**：BTC、ETH 等具备高流动性和明显趋势特征的加密资产。

---

## 系统架构总览

本系统采用经典的三重时间滤网（Triple Screen）架构，将核心操作周期锚定在 1H，通过跨周期的信号协同来提升胜率。

```
┌─────────────────────────────────────────────────────────────┐
│                        4H 宏观层                            │
│  职责：定调与宏观风控                                        │
│  功能：一票否决制 - 决定"只能做多"、"只能做空"或"空仓观望"   │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                        1H 执行层                            │
│  职责：信号生成核心                                          │
│  功能：识别市场结构，寻找EMA支撑/阻力，VWAP成本确认          │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│                        15m 微观层                           │
│  职责：精准入场与微观风控                                    │
│  功能：过滤假信号，动能衰竭时提前平仓                        │
└─────────────────────────────────────────────────────────────┘
```

---

## 核心模块说明

### 1. 宏观层 (MacroLayer) - 4H

**核心职责**：
- 方向许可：决定是否允许做多或做空
- 一票否决：当 1H 信号与 4H 方向相反时，直接否决

**关键指标**：
- EMA55：判断大趋势方向
- MACD (12, 26, 9)：宏观动能风控

**决策逻辑**：
```python
做多许可 = (4H价格 > EMA55) AND (MACD_4H不处于高位死叉) AND (无顶背离)
做空许可 = (4H价格 < EMA55) AND (MACD_4H不处于底背离金叉) AND (无底背离)
```

---

### 2. 执行层 (CoreLayer) - 1H

**核心职责**：
- 市场状态识别：强趋势 / 次级回调 / 无序震荡
- 趋势得分计算：评估趋势强度 (40分)
- 回撤得分计算：评估回踩质量 (20分)

**市场状态识别**：

| 状态 | 特征 | 系统行为 |
|------|------|----------|
| **强趋势 (TREND_ON)** | EMA21与EMA55发散，价格稳定在VWAP一侧 | 提升结构权重，弱化动能要求 |
| **次级回调 (PULLBACK)** | 价格穿透EMA21，受EMA55和VWAP支撑 | 提升动能权重，必须等待反转确认 |
| **无序震荡 (CHOP)** | 均线频繁交叉，价格围绕VWAP穿插 | **强制休眠，不生成信号** |

**核心捕捉模型**：EMA21 回踩二次启动
1. 第一波推升：1H 价格突破 VWAP 并带起均线多头排列
2. 回调阶段：1H K线缩量回落至 EMA21 附近
3. 启动确立：15m MACD 重新金叉，1H 收长下影或实体阳线

---

### 3. 微观层 (MicroLayer) - 15m

**核心职责**：
- 动能得分计算：评估入场时机 (20分)
- 衰竭信号检测：提前预警平仓防守

**动能评分**：
- 金叉：20分
- 柱子翻红：18分
- 柱子缩短且为正：15分
- 柱子为正：10分

**衰竭信号**：
- 顶背离/底背离
- MACD 死叉（多头持仓）
- 动能衰退（柱子连续缩短）

---

### 4. 分数融合引擎 (ScoreFusionEngine)

**评分体系**（总分 100 分）：

| 得分项 | 满分 | 说明 |
|--------|------|------|
| 1H 趋势得分 | 40 | 价格 > EMA21 > EMA55 且 价格 > VWAP |
| 1H 回撤得分 | 20 | 价格回踩 EMA21 且未跌破 EMA55 |
| 15m 动能得分 | 20 | MACD 柱子翻红或金叉 |
| 4H 顺势得分 | 20 | MACD_4H 零轴上方且柱体增长 |

**信号等级**：

| 等级 | 得分范围 | 仓位比例 | 说明 |
|------|----------|----------|------|
| **S 级** | 90-100 | 100% | 各周期共振，全仓出击 |
| **A 级** | 70-89 | 50% | 1H 结构成立，略有瑕疵，半仓入场 |
| **B 级** | <70 | 0% | 忽略信号 |

## 完整交易流程

### 开仓决策

```
步骤 1: 4H 方向许可检查
   └─ 通过 → 继续
   └─ 否决 → 结束

步骤 2: 1H 市场状态识别
   └─ 强趋势/回调 → 继续
   └─ 震荡 → 强制休眠

步骤 3: 多维度评分
   ├─ 1H 趋势得分 (40分)
   ├─ 1H 回撤得分 (20分)
   ├─ 15m 动能得分 (20分)
   └─ 4H 顺势得分 (20分)

步骤 4: 分数融合
   └─ S级 → 全仓入场
   └─ A级 → 半仓入场
   └─ B级 → 忽略

步骤 5: 风险评估
   └─ 风险回报比 >= 2.0 → 执行
   └─ 风险回报比 < 2.0 → 放弃
```

### 平仓决策

```
常规止盈：
   ├─ 到达 1H 前期结构高点/低点 → 平仓 50%
   └─ 风险回报比达标 (2.5:1 - 4:1) → 平仓剩余 50%

微观衰竭平仓 (15m)：
   ├─ 顶背离/底背离 + MACD 死叉/金叉 → 提前平仓 50%
   └─ 目的：锁定利润，防范假突破

绝对止损：
   ├─ 1H K线实体收盘在 EMA55 之下
   ├─ 跌破前序 1H 结构低点
   └─ 单笔最大亏损 1.5%

浮盈保护：
   ├─ 浮动盈利达到 1 ATR → 止损移至开仓均价
   └─ 以 1H EMA21 动态追踪止损
```

## 关键参数配置

### 技术指标参数

| 模块 | 指标 | 参数 | 核心作用 |
|------|------|------|----------|
| **4H (宏观)** | EMA | 21, 55 | 判断大趋势背景 |
| **4H (宏观)** | MACD | 12, 26, 9 | 宏观风控，一票否决 |
| **1H (执行)** | EMA | 21, 55, 200 | 判定市场状态，寻找支撑位 |
| **1H (执行)** | VWAP | 锚定模式 | 识别机构成本线 |
| **15m (微观)** | MACD | 8, 21, 5 | 精准入场，衰竭预警 |

### 风控参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 单笔最大风险 | 1.5% | 单笔交易最大亏损占总资金比例 |
| 最小风险回报比 | 2.0 | 进场必须满足的最小盈亏比 |
| 最大持仓数 | 3 | 同时持有的标的数量上限 |
| 最大日交易次数 | 5 | 每日最大交易次数 |
| 同标的最大止损次数 | 2 | 单一标的日内连续止损上限 |
| 止损后冻结时间 | 24小时 | 触发最大止损后的冷却期 |

## 核心原则总结

### 三大时间框架协同

1. **4H 定方向**：宏观一票否决制，防止逆大势入场
2. **1H 找结构**：核心执行层，EMA 回踩二次启动模型
3. **15m 抓时机**：精准入场点，衰竭预警防守

### 风险管理铁律

1. **单笔风险 ≤ 1.5%**：严格限制单笔最大亏损
2. **风险回报比 ≥ 2.0**：不满足盈亏比要求不进场
3. **震荡市场休眠**：无序震荡时系统强制空仓
4. **重入抑制机制**：连续止损后冻结 24 小时

### 浮盈保护机制

1. **保本触发**：盈利 1 ATR 后移动止损至成本
2. **动态追踪**：以 1H EMA21 作为移动止损线
3. **风控降维**：4H 出现反向势头时提前防守
