## 一、为什么必须动态调整

### 固定止损的三种失效场景

**失效场景 1：牛市中频繁被扫**

牛市日内波动率通常是震荡市的 1.5～2 倍。固定使用 1H 结构低点作为止损，在价格大幅波动的环境下，止损距离相对波动幅度太窄，容易在正常回调中被扫出，随后价格继续上涨。

典型表现：止损触发 → 价格立即反弹 → 错过主升浪。

**失效场景 2：熊市中亏损失控**

熊市下跌段的 ATR 通常是正常水平的 2～3 倍。若止损仍按"结构低点下方固定距离"设置，单笔止损损失可能达到账户的 3%～5%，超出风险控制上限。

**失效场景 3：震荡市中止损无意义**

震荡市价格在区间内反复横跳，任何"结构低点"都可能被频繁破坏再修复。固定止损在震荡市中既不保护本金，也无法有效识别趋势失效。

### 动态调整的核心逻辑

```
止损距离 = f(波动率环境, 结构位置, 账户风险上限)

不是固定距离，而是固定风险
```

目标：无论市场处于何种环境，每笔交易的最大止损金额占账户的比例保持恒定（建议 1%～1.5%），通过调整止损距离来反推合理仓位。

## 二、核心基准：ATR 止损框架

### 为什么选择 ATR(14)

ATR（Average True Range，平均真实波幅）是目前最适合作为止损基准的动态指标，原因如下：

- 自动反映当前市场的真实波动幅度，无需手动切换参数
- 对异常 K 线具有平滑效果（14 根均值，单根插针影响有限）
- 在 TradingView / Binance 等平台均可直接调用，计算简单

**参数设置：ATR(14)，基于 1H K 线。**

### ATR 与止损距离的基本关系

```
最小止损距离 = ATR(14) × 系数

系数根据市场状态动态变化：
  牛市：1.0 ～ 1.5
  震荡：0.8 ～ 1.2
  熊市：1.5 ～ 2.5
  极端行情：2.5 ～ 3.5
```

止损距离不得低于 `ATR × 0.8`，否则在正常波动中必然被触发（无效止损）。

### ATR 的波动率分级参考（BTC 1H）

| 市场环境 | ATR(14) 典型范围（USDT） | 占价格比例参考 |
|----------|--------------------------|---------------|
| 超低波动（震荡压缩） | 200 ～ 400 | 0.2% ～ 0.4% |
| 正常波动（标准趋势） | 400 ～ 800 | 0.4% ～ 0.8% |
| 高波动（趋势加速） | 800 ～ 1500 | 0.8% ～ 1.5% |
| 极端波动（黑天鹅级别） | > 1500 | > 1.5% |

> 以上以 BTC 价格约 95,000 USDT 为参考基准，需根据实际价格等比例调整。

## 三、市场状态识别标准

止损动态调整的前提是准确识别当前市场所处状态。使用以下量化标准。

### 状态一：牛市（趋势上涨）

**识别条件（满足 ≥ 4/5）：**

```
□ 4H：价格 > EMA21 > EMA55 > EMA200
□ 4H：MACD 持续 > 0 超过 10 根 K 线
□ 1H ATR(14) 高于过去 20 根 ATR 均值的 120%
□ 近 5 根 4H K 线中阳线数量 ≥ 4
□ Anchored VWAP 斜率向上（价格持续高于锚点 VWAP）
```

**ATR 特征：** 数值偏高，且呈现阶梯式抬升趋势。

---

### 状态二：震荡市（区间横盘）

**识别条件（满足 ≥ 3/4）：**

```
□ 4H：价格在 EMA21 与 EMA55 之间反复穿插
□ 4H：MACD 在零轴附近长时间钝化（< ± 0.1 × 历史均值）
□ 1H ATR(14) 低于过去 20 根 ATR 均值的 90%（波动收缩）
□ 近 10 根 4H K 线无法形成明显高点或低点的方向性序列
```

**ATR 特征：** 数值偏低，且横向走平或持续收缩。

---

### 状态三：熊市（趋势下跌）

**识别条件（满足 ≥ 4/5）：**

```
□ 4H：价格 < EMA21 < EMA55 < EMA200
□ 4H：MACD 持续 < 0 超过 10 根 K 线
□ 1H ATR(14) 高于过去 20 根 ATR 均值的 150%（恐慌性波动）
□ 近 5 根 4H K 线中阴线数量 ≥ 4
□ Anchored VWAP 斜率向下（价格持续低于锚点 VWAP）
```

**ATR 特征：** 数值明显偏高，且在下跌过程中持续扩大。

---

### 状态识别的优先级

当指标出现矛盾信号时，按以下优先级判断：

```
1. 4H MACD 方向（最高权重，动能的本质）
2. 4H 均线排列顺序（结构的直观表达）
3. 1H ATR 水平（波动率的当前状态）
4. 近期 K 线阴阳分布（价格行为的直接证据）
5. VWAP 斜率（资金成本的方向）
```

## 四、三种市场环境的止损参数

### 牛市止损参数

**核心逻辑：** 牛市中波动率偏高，趋势动能强，价格经常做出超正常的快速回调后继续上涨。止损需要足够宽，避免在正常回调中被扫出错过主升浪。

| 止损类型 | 计算公式 | 典型距离（BTC 95,000） |
|----------|----------|----------------------|
| 基础止损（1H 结构低点） | 结构低点 − ATR × 1.5 | 约 600 ～ 1,200 USDT |
| 加速段止损（无回踩时） | 当根 K 线低点 − ATR × 1.0 | 约 400 ～ 800 USDT |
| 主升浪移动止损 | 1H EMA21 − ATR × 0.5 | 动态跟随 |

**牛市止损特殊规则：**

```
1. 止损距离最小值：ATR × 1.0（低于此值必然被扫）
2. 止损距离最大值：ATR × 2.0（超出此值单笔亏损超限）
3. 首仓止损以 1H 结构低点为锚，不得仅用当根 K 线低点
4. 在 EMA21 偏差 > 3% 时入场，止损收紧至 ATR × 1.0
```

---

### 震荡市止损参数

**核心逻辑：** 震荡市波动率低，但价格反复横跳，需要以区间边界作为止损锚点，而非仅依赖 ATR 系数。

| 止损类型 | 计算公式 | 典型距离（BTC 95,000） |
|----------|----------|----------------------|
| 基础止损（区间低点） | 区间支撑位 − ATR × 0.8 | 约 250 ～ 500 USDT |
| 1H 结构止损 | 结构低点 − ATR × 0.6 | 约 200 ～ 400 USDT |
| 移动止损 | 1H EMA55 − ATR × 0.3 | 动态跟随 |

**震荡市止损特殊规则：**

```
1. 止损必须放在区间下轨之外（区间边界是最重要的止损参考）
2. ATR 系数取值范围：0.6 ～ 1.2（比牛市更窄）
3. 时间止损权重增加：5 根 1H K 线内不启动，直接减仓
4. 震荡市内禁止使用宽幅止损（ATR × 2.0 以上）
```

---

### 熊市止损参数（做空）

**核心逻辑：** 熊市 ATR 往往极高，固定百分比止损会导致仓位极小、操作频率低；应以结构高点和日均波幅双重约束来设置止损上限。

| 止损类型 | 计算公式 | 典型距离（BTC 95,000） |
|----------|----------|----------------------|
| 基础止损（1H 结构高点） | 结构高点 + ATR × 1.5 | 约 900 ～ 2,250 USDT |
| 反弹段止损（空头回踩） | 当根 K 线高点 + ATR × 1.0 | 约 600 ～ 1,500 USDT |
| 主跌浪移动止损 | 1H EMA21 + ATR × 0.5 | 动态跟随 |

**熊市止损特殊规则：**

```
1. 止损距离上限：ATR × 2.5（超出则仓位压缩至 10% 以下）
2. ATR 急剧扩大时（> 均值 200%），仓位自动减半，止损比例不变
3. 熊市中做多仓位严格禁止，所有止损规则仅适用于空头仓位
4. 反弹段做空的止损：以前一个 1H 反弹高点为锚，加 ATR × 1.0
```

## 五、止损计算的完整公式

### 通用止损计算公式

```
止损价格（做多）= max(1H结构低点, EMA55) − ATR × K

其中 K（止损系数）根据市场状态和入场位置确定：

┌─────────────────────────────────────────────────────┐
│  市场状态  │  标准入场  │  偏离 2%～3% 入场  │  加速段入场  │
├───────────┼───────────┼──────────────────┼───────────┤
│  牛市      │   1.5      │       1.0         │    1.0    │
│  震荡市    │   0.8      │       0.6         │    0.6    │
│  熊市做空  │   1.5      │       1.2         │    1.0    │
└─────────────────────────────────────────────────────┘
```

### 止损价格的双重校验

每次计算止损价格后，必须经过两步校验：

**校验 1：止损距离合理性**

```
止损距离 = |入场价 − 止损价|

合理范围：ATR × 0.6 ≤ 止损距离 ≤ ATR × 3.0

若 < ATR × 0.6：止损过紧，上移至 ATR × 0.8
若 > ATR × 3.0：止损过宽，缩小仓位（见第六章）
```

**校验 2：最大亏损金额控制**

```
最大亏损金额 = 仓位数量 × 止损距离

上限：账户总资金 × 1.5%

若超出：仓位 = (账户总资金 × 1.5%) / 止损距离
```

---

### 波动率修正系数（VAF）

当 ATR 出现极端变化时，引入波动率修正系数对止损系数 K 进行调整：

```
VAF（波动率修正系数）= 当前 ATR(14) / ATR(14) 过去 20 根均值

VAF < 0.7（波动率异常低） → K 系数 × 0.8（止损收紧）
0.7 ≤ VAF ≤ 1.3（正常范围） → K 系数不变
1.3 < VAF ≤ 2.0（波动率偏高） → K 系数 × 1.2（止损放宽）
VAF > 2.0（极端波动） → 触发止损熔断（见第八章）
```

**含义：** 当市场波动率突然放大时，固定 ATR 系数的止损距离会自动变宽，但超过 2 倍均值后需要额外放宽以适应真实波动。

## 六、止损与仓位的联动机制

动态止损的核心是"固定风险金额，反推合理仓位"，而不是"固定仓位，调整止损"。

### 仓位计算公式

```
标准仓位（合约张数或 BTC 数量）：

仓位 = (账户总资金 × 单笔风险比例) / 止损距离

其中：
  单笔风险比例：标准 1.0%，最大 1.5%
  止损距离：按第五章公式计算
```

### 三种市场环境的仓位对比示例

假设：账户总资金 10,000 USDT，单笔风险 1.0%（即最大亏损 100 USDT）

**牛市（ATR = 800 USDT，止损系数 1.5）：**

```
止损距离 = 800 × 1.5 = 1,200 USDT
仓位 = 100 / 1,200 = 0.083 BTC
占账户比例 = 0.083 × 95,000 / 10,000 = 79%（高杠杆环境需折算）
```

**震荡市（ATR = 350 USDT，止损系数 0.8）：**

```
止损距离 = 350 × 0.8 = 280 USDT
仓位 = 100 / 280 = 0.357 BTC
```

**熊市做空（ATR = 1,200 USDT，止损系数 1.5）：**

```
止损距离 = 1,200 × 1.5 = 1,800 USDT
仓位 = 100 / 1,800 = 0.056 BTC
```

**结论：** 相同风险金额下，熊市仓位最小（波动率最高），震荡市仓位最大（波动率最低），这与直觉相符——震荡市确定性更高时可以适当增加仓位。

### 三笔仓位的止损联动

系统使用 40% / 30% / 30% 三笔建仓，每笔止损价格可以不同：

| 仓位 | 比例 | 止损价格 | 止损逻辑 |
|------|------|----------|----------|
| 首仓 | 40% | 1H 结构低点 − ATR × K | 最宽，给趋势呼吸空间 |
| 确认仓 | 30% | 止损提至开仓价附近 | 首仓浮盈后保本 |
| 加速仓 | 30% | 跟随 1H EMA21 动态移动 | 最紧，紧贴趋势 |

## 七、移动止损的动态规则

### 牛市移动止损

**三阶段移动：**

```
阶段 1（浮盈 < ATR × 1.0）：
  止损保持在原始 1H 结构低点 − ATR × 1.5
  目的：给首仓足够的呼吸空间

阶段 2（浮盈达到 ATR × 1.0 ～ 2.0）：
  止损上移至开仓价 − ATR × 0.3（接近保本）
  触发条件：1H 出现第一个新的高点低点均抬高

阶段 3（浮盈 > ATR × 2.0）：
  止损跟随 1H EMA21 动态上移
  具体位置：EMA21 − ATR × 0.5
  更新频率：每根 1H K 线收盘后重新计算
```

**牛市移动止损的特殊处理：**

```
当价格偏离 EMA21 超过 ATR × 3 时：
  止损收紧至最近 15m 结构低点（防止浮盈全部归还）

当出现连续 3 根 1H 上涨 K 线后：
  止损上移至第一根上涨 K 线低点（锁定趋势启动点）
```

---

### 震荡市移动止损

**震荡市中移动止损更为保守：**

```
浮盈达到止损距离的 100%（即 1:1 盈亏比）：
  止损上移至开仓价（保本止损，立即执行）

浮盈达到止损距离的 150%：
  止损上移至开仓价 + ATR × 0.3
  
到达区间上轨 80% 位置时：
  止损上移至区间中轴（不等待指标信号）
```

**原因：** 震荡市目标本就是区间利润（有限），必须更积极地锁定浮盈。

---

### 熊市移动止损（做空）

```
阶段 1（浮盈 < ATR × 1.0）：
  止损保持在原始 1H 结构高点 + ATR × 1.5

阶段 2（浮盈达到 ATR × 1.0 ～ 2.0）：
  止损下移至开仓价 + ATR × 0.3（接近保本）

阶段 3（浮盈 > ATR × 2.0）：
  止损跟随 1H EMA21 动态下移
  具体位置：EMA21 + ATR × 0.5
  更新频率：每根 1H K 线收盘后重新计算
```

## 八、极端波动的止损熔断

### 止损熔断触发条件

当 ATR 出现以下情况，进入止损熔断状态：

```
ATR(14) > 过去 20 根 ATR 均值 × 2.5
或
单根 1H K 线实体 > ATR(14) × 3.0
```

### 熔断状态下的止损处理

**已持仓：**

```
1. 立即将止损收紧至最近 1H 低点（不用 ATR 系数，直接用价格结构）
2. 仓位减至 50%（无论当前浮盈或亏损）
3. 剩余仓位使用"跟踪止损"：每根 1H K 线更新一次，永不后退
```

**新入场：**

```
1. 禁止使用标准 ATR 系数（ATR 太大会导致止损距离不可接受）
2. 改用固定百分比止损：入场价 × 1.5%（做多方向）
3. 仓位压缩至正常仓位的 30%
```

### 熔断解除条件

```
□ ATR(14) 回落至过去 20 根均值的 150% 以下
□ 连续 5 根 1H K 线 ATR 持续回落（不再扩大）
□ 最大单根 K 线振幅 < ATR × 2.0
```

满足全部 3 条后，恢复正常 ATR 系数计算。

## 九、实战计算示例

### 示例 1：牛市标准入场

**市场参数：**

```
BTC 当前价：95,000 USDT
1H ATR(14)：750 USDT
市场状态：牛市（4H EMA 多头排列，MACD > 0）
ATR 均值（20根）：650 USDT
VAF = 750 / 650 = 1.15（正常范围，系数不变）
```

**入场参数：**

```
入场价：95,000 USDT（15m 回踩 1H EMA21 后，5m 金叉入场）
1H 最近结构低点：94,200 USDT
止损系数 K：1.5（牛市标准入场）
```

**止损计算：**

```
止损价 = max(结构低点, EMA55) − ATR × K
       = 94,200 − 750 × 1.5
       = 94,200 − 1,125
       = 93,075 USDT

止损距离 = 95,000 − 93,075 = 1,925 USDT
```

**校验：**

```
止损距离下限：ATR × 0.6 = 450 ✓（1,925 > 450）
止损距离上限：ATR × 3.0 = 2,250 ✓（1,925 < 2,250）
```

**仓位计算（账户 10,000 USDT，单笔风险 1.0%）：**

```
首仓（40%）仓位 = (10,000 × 1.0%) / 1,925 = 0.052 BTC
名义价值 = 0.052 × 95,000 = 4,940 USDT（约占账户 49%）
```

### 示例 2：震荡市入场

**市场参数：**

```
BTC 当前价：95,000 USDT
1H ATR(14)：320 USDT
市场状态：震荡（价格在 4H EMA21 和 EMA55 之间横盘）
区间支撑：94,500 USDT，区间阻力：96,000 USDT
VAF = 320 / 360 = 0.89（正常范围下限，系数 × 0.8 修正）
```

**止损计算：**

```
止损价 = 区间支撑位 − ATR × 0.8 × VAF修正（0.8）
       = 94,500 − 320 × 0.8 × 0.8
       = 94,500 − 205
       = 94,295 USDT

止损距离 = 95,000 − 94,295 = 705 USDT
```

**仓位计算：**

```
首仓（40%）仓位 = (10,000 × 1.0%) / 705 = 0.142 BTC
名义价值 = 0.142 × 95,000 = 13,490 USDT（约占账户 135%，需使用杠杆）
```

> 注意：若不使用杠杆，震荡市的最大仓位受账户资金约束，按实际资金比例调整。

### 示例 3：熊市做空

**市场参数：**

```
BTC 当前价：95,000 USDT（反弹后在 1H EMA21 处做空）
1H ATR(14)：1,100 USDT
市场状态：熊市（4H EMA 空头排列，MACD < 0）
1H 最近结构高点：95,800 USDT
VAF = 1,100 / 850 = 1.29（接近高波动，系数 × 1.2）
```

**止损计算：**

```
止损价 = 结构高点 + ATR × 1.5 × VAF修正（1.2）
       = 95,800 + 1,100 × 1.5 × 1.2
       = 95,800 + 1,980
       = 97,780 USDT

止损距离 = 97,780 − 95,000 = 2,780 USDT
```

**校验：**

```
止损距离上限：ATR × 3.0 = 3,300 ✓（2,780 < 3,300）
```

**仓位计算：**

```
首仓（40%）仓位 = (10,000 × 1.0%) / 2,780 = 0.036 BTC
名义价值 = 0.036 × 95,000 = 3,420 USDT（约占账户 34%）
```

## 十、实战检查清单

每次入场前，按以下顺序完成止损计算：

### 步骤 1：确认市场状态

```
[ ] 识别当前市场状态（牛市 / 震荡 / 熊市）
[ ] 查看 1H ATR(14) 数值
[ ] 计算 VAF = 当前 ATR / 过去 20 根 ATR 均值
[ ] 确认 VAF 是否触发熔断（> 2.5）
```

### 步骤 2：选择止损系数

```
市场状态  ×  入场位置  →  确定基础系数 K

[ ] 牛市标准入场 → K = 1.5
[ ] 牛市偏离入场（偏差 2%～3%）→ K = 1.0
[ ] 震荡市入场 → K = 0.8
[ ] 熊市做空标准入场 → K = 1.5
[ ] 加速段入场（任何市场）→ K = 1.0

VAF 修正：
[ ] VAF < 0.7 → K × 0.8
[ ] VAF 在 0.7 ～ 1.3 → K 不变
[ ] VAF 在 1.3 ～ 2.0 → K × 1.2
[ ] VAF > 2.0 → 触发止损熔断规则
```

### 步骤 3：计算止损价格

```
[ ] 确认 1H 结构低点（做多）或结构高点（做空）
[ ] 止损价 = 结构位 ± ATR × K（修正后）
[ ] 校验止损距离：ATR × 0.6 ≤ 距离 ≤ ATR × 3.0
```

### 步骤 4：联动计算仓位

```
[ ] 最大亏损金额 = 账户 × 1.0%（最大 1.5%）
[ ] 首仓仓位 = 最大亏损金额 / 止损距离
[ ] 检查仓位是否超过账户的合理比例
```

### 步骤 5：设置移动止损计划

```
[ ] 确认三个移动止损阶段的触发价格
[ ] 在交易平台设置条件单或提醒
[ ] 记录当前 ATR 数值（用于后续更新）
```

## 十一、待讨论议题

### 议题 1：ATR 周期参数的选择

当前方案使用 ATR(14)，但对于 BTC 的日内交易，ATR(14) 可能过于平滑，低估近期的真实波动。建议讨论：

- ATR(7) 对近期波动更敏感，但容易被单根异常 K 线影响，是否更适合加速行情的止损？
- ATR(20) 更稳健，但在波动率快速上升时反应滞后，是否适合熊市阶段？
- 是否考虑使用双周期 ATR（短期 ATR 与长期 ATR 的比值）来识别波动率状态变化？

### 议题 2：固定风险比例的合理性

方案设定单笔最大风险为账户的 1.0%～1.5%，这一数值来自经典仓位管理理论，但对于不同账户规模可能不适用：

- 小账户（< 1,000 USDT）：1% = 10 USDT，在高 ATR 环境下几乎无法开有意义的仓位
- 大账户（> 100,000 USDT）：1% = 1,000 USDT，单笔风险金额是否需要绝对上限？
- 是否应该区分"首仓风险"和"总仓位风险"分别设置上限？

### 议题 3：市场状态切换时的止损处理

当市场从牛市切换到震荡市（或震荡到熊市）时，已有持仓的止损如何处理：

- 是否立即按新状态的止损系数重新计算？（可能导致止损大幅收紧，增加被扫概率）
- 是否保持原有止损直到该笔单子结束？（可能在新环境下止损过宽）
- 建议方案：状态切换后，新开仓使用新系数，已有持仓的止损只允许向有利方向移动（只收紧，不放宽）

### 议题 4：VAF 修正系数的实际操作性

VAF 需要每笔入场前实时计算，手动操作存在以下挑战：

- 20 根 ATR 均值是否容易在 TradingView 中直接读取，还是需要自定义指标？
- 是否可以简化为三档判断（ATR 低于均值 / 正常 / 高于均值），而不使用连续数值？
- 建议在 TradingView 自定义指标中预置 VAF 实时计算和颜色预警，减少手动计算错误
