## 1. 结论先行

### 1.1 实盘亏损主因

2026-04-25 的实盘亏损主因不是“没有开仓”或“挂单没成交”，而是:

1. 开仓链路在 14:00 UTC 之后已经恢复，能够正常发出开仓单。
2. 当晚真正成交的几笔，主要是追在趋势延续的后半段。
3. 尤其是 `VETUSDT` 与 `DOGEUSDT` 的空单，开仓后几乎没有继续顺势下跌空间，随后横盘或小幅反抽，最终被保护单/被动平仓抹掉。
4. `MORPHOUSDT` 的多单不如前两者极端，但同样缺乏明显顺势扩展，入场后只出现极小浮盈，随后回落。

### 1.2 对“是否每次买在行情末期导致亏损”的判断

结论不是“每一笔都能 100% 定义为末期追单”，但 2026-04-25 这批亏损单的共性非常强:

- `VETUSDT` 三次空单和 `DOGEUSDT` 一次空单，本质上都更像“空在下跌段后半程或衰竭段”。
- `MORPHOUSDT` 多单不是典型大幅追高，但也缺乏足够的 15m 延续确认，属于“刚启动不足以证明能继续扩展就先上车”。

更准确的表述应当是:

> 这批亏损不是由单一 BUG 导致的假开仓，而是由“开仓恢复后，策略优先抓到了延续末段信号”导致。

### 1.3 记账日志缺陷

`trade_fills_utc.csv` 在 2026-04-25 存在两个独立问题:

1. 手续费全被记成了正数，应该统一记为负数。

这不是单纯的“PnL 字段没算对”，而是“平仓成交未被完整收集”。

## 4. 本次实盘暴露出的两个非策略缺陷

### 4.1 成交回报 CSV 只稳定记录了本地下发订单的 fills

当前代码路径:

- `src/app/fund_flow_bot.py`
- `_write_trade_fill_log()`
- `_fetch_order_trade_fills()`

原始行为问题:

1. 本地下发后的订单可以通过 `orderId` 查询并落盘。
2. 但保护单、止损单、交易所侧被动触发的平仓，不一定会走同一条本地下发回调链。
3. 结果就是仓位已经消失，但 CSV 中没有对应平仓 fill。

### 4.2 手续费符号错误

原始行为问题:

- `commission` 被直接写入 CSV。
- Binance 返回的是正数数值，但会计口径里手续费应记作成本，应该统一写成负数。

## 6. BOLL -> RSI 替换评审草案

本次只提出评审方向，不直接实现。

### 6.1 当前 BOLL 在策略中的三处核心作用

当前策略里，BOLL 主要承担三类职责:

1. 结构层:
   - `check_boll_structure()`
   - 通过 1H / 4H 价格相对 BOLL 中轨与带宽位置，决定 strong / normal / weak
2. 偏离否决:
   - `check_boll_deviation_veto()`
   - `flip_bullish / flip_bearish` 时，如果价格远离中轨且超带，直接否决
3. 15m 入场精化:
   - `evaluate_15m_entry()` 里的 `midline_bounce / midline_reject`
   - 通过 15m 回踩或回抽中轨，对入场分做强化或削弱

### 6.2 RSI 替换应遵守的原则

如果换 RSI，不建议只做“把 BOLL 字段名替换成 RSI 字段名”。
应该把这三类职责分别映射:

1. 结构层改成“趋势强弱区间”
   - long:
     - `RSI_1H > 52` 且 `RSI_4H > 50` -> strong / normal
   - short:
     - `RSI_1H < 48` 且 `RSI_4H < 50` -> strong / normal
2. 偏离否决改成“过热/过冷否决”
   - `flip_bullish` 时若 `RSI_1H > 72`，不追
   - `flip_bearish` 时若 `RSI_1H < 28`，不追
3. 15m 精化改成“回踩中性带后的再发力”
   - long:
     - `RSI_15m` 从 `48-55` 区域二次拐头向上 -> 加分
   - short:
     - `RSI_15m` 从 `45-52` 区域二次拐头向下 -> 加分

### 6.3 为什么值得评审 RSI 方案

从 2026-04-25 的实盘表现看，当前 BOLL 精化存在一个问题:

- 它更容易描述“价格在带中的位置”
- 但不一定能描述“当前动量是否已经衰减到不值得追”

而这次亏损的核心恰恰就是:

- 入场方向未必错
- 但入场时点太靠后

所以 DeepSeek 评审重点应当是:

> RSI 是否能比当前 BOLL 中轨/带宽逻辑，更早识别“趋势已衰减、延续性不足”的 15m/1H 末段信号。
