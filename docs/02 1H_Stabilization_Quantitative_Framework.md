## 一、框架设计逻辑

### 核心问题

原始定义"MACD 红柱停止缩短"存在三个执行层面的缺陷：

- **边界模糊**：停止缩短是指绝对停止，还是放缓即算？
- **维度单一**：仅依赖 MACD 一个指标，忽略价格结构、量能等关键信息
- **无分级输出**：只能得出"是/否"的二元结论，无法区分信号强弱

### 解决思路

将"企稳"分解为五个可独立量化的维度，每个维度设置精确数值阈值，最终汇总为 0～100 的综合分数，再映射到四个入场等级。

### 打分原则

```
总分 = MACD动能分 + 价格结构分 + 成交量分 + K线形态分 + 时间结构分
入场条件 = 总分 ≥ 70 AND 否决项全部为空
```

## 二、五维度权重分配

| 维度 | 满分 | 权重 | 核心逻辑 |
|------|------|------|----------|
| MACD 动能 | 30 分 | 30% | 动能衰减是回调结束的核心信号 |
| 价格结构 | 30 分 | 30% | 价格位置决定回调深浅与风险 |
| 成交量 | 20 分 | 20% | 量价配合是趋势质量的直接体现 |
| K 线形态 | 12 分 | 12% | 辅助确认，单独使用噪声较大 |
| 时间结构 | 8 分 | 8% | 过滤回调过短或过长两种极端 |
| **合计** | **100 分** | **100%** | |

**权重设计依据**：MACD 与价格结构合占 60%，因二者最直接反映趋势动能的衰减状态。成交量（20%）是第三重要的确认维度，量价背离是最常见的假信号来源。K 线形态和时间结构仅作辅助加分，单独不能构成入场依据。

## 三、维度一：MACD 动能（30 分）

### 评分细则

| 条件 | 量化标准 | 得分 |
|------|----------|------|
| 连续缩短 | 连续 ≥2 根柱子绝对值递减：H(n) < H(n-1) < H(n-2) | +8 |
| 衰减幅度 | 最新柱高度 / 前柱高度（ratio）< 0.5 | +10 |
| 斜率趋平 | MACD 线斜率趋平，DIF-DEA 差值收窄，不再加速 | +7 |
| 未死叉 | 柱子绝对值仍 > 0（红柱），DIF 在 DEA 上方 | +5 |

### 衰减幅度分级

```
ratio = H(n) / H(n-1)

ratio < 0.30  → 强势衰减：+10分，信号极强
ratio < 0.50  → 标准衰减：+10分，信号良好
ratio < 0.70  → 弱势衰减：+5分，信号一般
ratio ≥ 0.70  → 几乎未衰减：0分，不达标
```

### 关键说明

连续缩短的判定必须是**序列衰减模式**，而非单根停止：

```
合格：H5 < H4 < H3（连续 3 根递减）✓
合格：H5 < H4（连续 2 根递减）✓
不合格：H4 < H3，但 H5 > H4（中断后反弹）✗
```

一根停止、下一根继续扩大，是反弹结束的早期信号，不算企稳，应视为假信号。

## 四、维度二：价格结构（30 分）

### 评分细则

| 条件 | 量化标准 | 得分 |
|------|----------|------|
| EMA21 偏差率 | \|收盘价 - EMA21\| / EMA21 ≤ 0.5% | +12 |
| EMA55 不破 | 1H 收盘价在 EMA55 上方 | +8 |
| VWAP 上方 | 价格维持在日内 VWAP 上方（做多时） | +6 |
| EMA21 斜率 | EMA21 当前值 ≥ 3 根前 EMA21 值（方向向上） | +4 |

### EMA21 偏差率分级

```
偏差率 = |收盘价 - EMA21| / EMA21 × 100%

≤ 0.5%      → 满分 12 分（贴近均线，轻量回调）
0.5% ～ 1.0% → 6 分（可接受，适当降低首仓）
> 1.0%      → 0 分（偏离过远，不建议入场）
```

### BTC 场景参考

```
假设 EMA21 = 95,000 USDT

满分区间：94,525 ～ 95,475（± 475 USDT）
合格区间：94,050 ～ 95,950（± 950 USDT）
超出区间：< 94,050 或 > 95,950 → 0分
```

### 关键说明

EMA21 偏差率是整套系统权重最高的单项指标（12 分），直接量化了"回调轻重"。偏差超过 1% 基本意味着这次回调已不是正常换手，而是主动出逃，此时入场等于接刀。

## 五、维度三：成交量（20 分）

### 评分细则

| 条件 | 量化标准 | 得分 |
|------|----------|------|
| 量比达标 | 回调段总量 / 前一上涨段总量 < 0.60 | +10 |
| 连续萎缩 | 最近 3 根 1H K 线量能逐根递减 | +6 |
| 绝对水平 | 当前 1H K 线量 < 量 MA20 | +4 |

### 回调量比分级

```
量比 = 回调段总量 / 前一上涨段总量

量比 < 0.60  → 满分 10分（回调量不足上涨量 60%，卖压惰性）
量比 < 0.80  → 5分（量比偏高，谨慎）
量比 ≥ 0.80  → 0分（回调量过大，趋势质量存疑）
量比 > 1.00  → 触发否决项（回调量超过上涨量，趋势疑似反转）
```

### 连续萎缩判定

```
标准：V(n) < V(n-1) < V(n-2)

连续 3 根递减 → +6分
连续 2 根递减 → +3分
未满足 → 0分
```

### 关键说明

量比是成交量维度的核心指标，低于 60% 说明卖盘是惰性的、非主动的，是真正的正常回调；超过 80% 则高度怀疑趋势已悄悄反转。

## 六、维度四：K 线形态（12 分）

### 评分细则

| 形态 | 量化标准 | 得分 |
|------|----------|------|
| 下影线承接 | 下影线 ≥ 实体 × 1.5，且下影 > 上影 | +5 |
| 十字星 / 小实体 | 实体 < ATR(14) × 0.30 | +4 |
| 横盘收敛 | 连续 ≥2 根小阴线，波动区间逐步收窄 | +3 |

### 各形态说明

**下影线承接（+5分）**

说明买方在低位有效承接，回调时有真实买盘介入。影线越长、承接越强，但需配合缩量才有效。

**十字星 / 小实体（+4分）**

ATR(14) 可用最近 14 根 1H K 线的均值振幅近似计算。小实体说明多空均衡，卖方动能耗尽，配合缩量时信号质量最高。

**横盘收敛（+3分）**

连续 2 根以上小阴线，每根实体依次缩小，说明空方动能逐步衰竭，即将切换方向。

### 关键说明

K 线形态权重最低（12 分），**不能作为主要判断依据**，只能辅助加分。原因：单根 K 线形态噪声大，必须配合前四个维度达标才有效，单独出现下影线不能视为企稳信号。

## 七、维度五：时间结构（8 分）

### 评分细则

| 条件 | 量化标准 | 得分 |
|------|----------|------|
| 回调根数 | 回调持续 3～5 根 1H K 线 | +4 |
| 低点结构 | 本次回调低点高于上一次回调低点 | +2 |
| 回调幅度 | 4H 级别回调幅度 < 前一段涨幅的 50% | +2 |

### 回调根数分级

```
回调持续时间（1H K 线根数）：

3 根     → +4分（较快，强势信号）
4～5 根  → +4分（标准，健康回调）
6～8 根  → +2分（偏长，开始警惕）
> 8 根   → 0分（已接近趋势变性质）
< 3 根   → 0分（过快，假信号概率高）
```

### 回调幅度计算

```
回调深度 = (回调高点 - 回调低点) / (回调高点 - 前一启动低点)

< 50%     → +2分（健康，主趋势完整）
50% ～ 61.8% → +1分（黄金比例区间，可接受）
> 61.8%   → 0分（开始质疑趋势完整性）
```

### 关键说明

时间维度的主要作用是**排除极端情况**：回调太短（< 3 根，假信号概率极高）和回调太长（> 8 根，趋势已变性质）。这两种情况即使其他维度得分高，也应主动降低仓位至 20%。

## 八、否决项系统

**否决项独立于分数之外，任一触发立即禁止入场，与总分无关。**

设计原因：防止"凑分通过"——即便四个维度勉强凑到 70 分，但 1H 价格已收盘于 EMA55 下方，该笔单子的期望值为负。

### 四大否决项

| 否决条件 | 触发标准 | 说明 |
|----------|----------|------|
| EMA55 跌破 | 1H 收盘价 < 1H EMA55 | 趋势结构破坏，非轻量回调 |
| MACD 死叉 | 柱子绝对值转负（翻绿） | 动能已确认反转 |
| 大阴线出现 | 1H 单根阴线实体 > 2× ATR(14) | 主动抛售，非自然回调 |
| 量能突放 | 单根 1H 成交量 > MA20 × 200% | 恐慌性抛售信号 |

## 十、动态门槛调整

根据市场状态动态调整入场门槛，而非固定 70 分：

### 强趋势市场（门槛降低至 65 分）

触发条件：
```
4H：EMA21 > EMA55 > EMA200（多头完美排列）
4H：MACD 持续 > 0 超过 10 根 K 线
价格：距前期高点 < 5%
```

逻辑：强趋势中回调质量普遍较低但不影响后续走势，适当降低入场标准可提升参与度。

### 正常趋势市场（标准门槛 70 分）

触发条件：
```
4H：方向明确（满足 ≥3/4 条件）
多空偶有分歧，但方向整体清晰
```

### 震荡 / 不明市场（门槛提高至 80 分）

触发条件：
```
4H：条件仅满足 3/4（边缘状态）
多空方向边界模糊
近期出现过虚假突破
```

逻辑：方向本身存疑时，必须要求更高质量的企稳信号才能入场，否则赔率不足。

## 十一、关键阈值汇总

以下三个阈值是整套框架最重要的数值边界，建议专家组重点讨论与验证：

### 阈值一：MACD 衰减率 < 0.5

```
公式：ratio = H(n) / H(n-1)
门槛：ratio < 0.5（即当前柱不足前柱 50%）
```

意义：小于 0.5 意味着每根柱子的推进力不足前根的一半，是卖方力量真实耗竭的量化信号，而非短暂喘息。该阈值来自对"动能减半即接近衰竭"这一经验规律的量化。

验证建议：回测过去 6 个月 BTC 1H 数据，统计 ratio < 0.5 后 3 根 K 线方向的胜率。

### 阈值二：EMA21 偏差率 < 0.5%

```
公式：偏差率 = |收盘价 - EMA21| / EMA21 × 100%
门槛：偏差率 < 0.5%
```

意义：直接量化了"回调是否轻量"。偏差超过 1% 基本说明市场在主动远离均线，此时入场等于接刀，而非捡筹码。

验证建议：BTC 日内波动率约 1.5%～3%，0.5% 约对应波动率的 1/4，可根据不同波动率环境（平静期 / 活跃期）分别统计最优阈值。

### 阈值三：回调量比 < 0.6

```
公式：量比 = 回调段总量 / 前一上涨段总量
门槛：量比 < 0.6
```

意义：低于 60% 说明卖盘是惰性的、非主动的，是真正的正常回调；超过 80% 则高度怀疑趋势已悄悄反转，大量筹码在借反弹出货。

验证建议：该阈值对计价方式敏感（按张数或按 USDT），建议统一使用 USDT 计价成交量作为标准。

## 十二、实战检查清单

每次等待 1H 企稳时，按以下顺序逐项检查：

### 第一步：否决项扫描（任一触发 → 停止，等待下一根 K 线）

```
[ ] 1H 收盘价是否在 EMA55 上方？
[ ] MACD 柱子是否仍为正值（红柱）？
[ ] 最近 1H 是否出现大阴线（实体 > 2× ATR）？
[ ] 成交量是否有突放（> MA20 × 200%）？
```

### 第二步：五维度评分

```
MACD 动能（满分 30）
[ ] 连续 ≥2 根柱子缩短                            +8
[ ] 最新柱 / 前柱 < 0.5                            +10
[ ] MACD 线斜率趋平                                +7
[ ] 柱子仍为正值                                   +5

价格结构（满分 30）
[ ] 收盘价距 EMA21 偏差 < 0.5%                     +12
[ ] 价格在 EMA55 上方                               +8
[ ] 价格在 VWAP 上方                               +6
[ ] EMA21 斜率向上                                 +4

成交量（满分 20）
[ ] 回调量 / 上涨量 < 0.60                          +10
[ ] 最近 3 根 1H K 线量能连续萎缩                   +6
[ ] 当前量 < 量 MA20                               +4

K 线形态（满分 12）
[ ] 出现下影线（影线 ≥ 实体 1.5 倍）                +5
[ ] 出现十字星或小实体（< ATR × 0.3）               +4
[ ] 连续 ≥2 根小阴线横盘收敛                        +3

时间结构（满分 8）
[ ] 回调持续 3～5 根 1H K 线                        +4
[ ] 本次低点高于上次低点                            +2
[ ] 4H 回调幅度 < 前段涨幅 50%                      +2

总分：______ / 100
```

### 第三步：判定入场等级

```
总分 ≥ 85 → A 级：首仓 40%，快速推进
总分 ≥ 70 → B 级：首仓 40%，正常执行
总分 ≥ 55 → C 级：首仓 20%，等待补分
总分 < 55 → D 级：禁止入场，继续等待
```

## 十三、待讨论议题

### 议题 1：阈值的市场适配性

三个核心阈值（MACD 衰减率 0.5、EMA21 偏差率 0.5%、量比 0.6）均来自经验判断，建议通过以下方式验证：

- 回测 BTC 过去 12 个月 1H 数据，统计各阈值组合下的入场胜率
- 分别在牛市（单边上涨）、熊市（单边下跌）、震荡市下统计表现差异
- 评估是否需要为不同市场状态设置独立的阈值参数集

### 议题 2：权重分配的合理性

当前 MACD（30）: 价格（30）: 量能（20）: K线（12）: 时间（8）的权重分配是否合理？

争议点：部分交易者认为成交量（尤其在加密市场刷量普遍的情况下）权重不应超过 K 线形态，建议讨论是否调整为 MACD（30）: 价格（35）: 量能（15）: K线（15）: 时间（5）。

### 议题 3：否决项的完备性

当前四个否决项是否足够？建议讨论以下候选条件是否应纳入否决系统：

- 4H MACD 突然死叉（更高级别信号反转）
- 价格在 1H EMA21 下方连续收盘超过 3 根
- 大级别（4H）新闻事件导致的异常波动

### 议题 4：C 级入场的价值

55～69 分的 C 级企稳是否值得入场（首仓 20%）？

正方：早入场可以获得更优的价格，即使首仓小也能通过后续加仓扩大利润。

反方：信号质量不足时入场，主要风险在于止损被触发后的心态管理，建议直接跳过 C 级，统一以 70 分作为最低门槛。
