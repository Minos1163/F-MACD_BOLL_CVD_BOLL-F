  - 提出新的评审重点: `RSI` 应作为比 `MACD` 更敏捷的节奏层，而不是被 `MACD` 完全压制的附属过滤器

## 1. 结论先行

### 1.1 最近一轮“压缩开仓数”没有带来想要的收益改善

最近一轮调整的思路是:

- 把 `min_signal_score` 统一抬到 `0.97`
- 把 `min_vwap_score_for_entry` 从 `0.10` 逐步抬高到 `0.15 / 0.16`
- 目标是把 30 天开仓数压到 `90-120`

实际结果表明:

1. 交易数确实下降了
2. 但胜率没有出现显著提升
3. 收益反而继续下降
4. 说明“进一步抬总分门槛 / 继续依赖 VWAP 过滤”不是当前最优方向

### 1.2 当前更应追求“提高胜率和收益”，不再强求 90-120 次开仓

新的目标优先级应调整为:

1. 先恢复更有 alpha 的入场机会集
2. 再通过更好的时机识别提高胜率与收益
3. 开仓次数不再作为第一约束

换句话说:

> 当前问题不是“交易太多”，而是“如何更早识别趋势启动与衰减，避免把高质量机会和尾段垃圾单一起砍掉”。

### 1.3 RSI 应承担“敏捷节奏层”职责，而不是 MACD 的从属过滤器

下一轮优化方向建议改为:

- 把 `min_signal_score` 退回 `0.85`
- 把 `min_vwap_score_for_entry` 退回 `0.10`，甚至允许更低
- 用 `RSI` 提高与 `MACD` 的共振质量
- 但不能把 `RSI` 简化成“必须和 MACD 同方向才有效”的迟钝确认器

核心要求是:

> `RSI` 要对 `MACD` 的延后做出敏捷反应，但不能因为与 `MACD` 暂时矛盾，就失去它作为早期节奏探测器的价值。

## 3. 为什么说 VWAP 不是当前最该加权的 alpha

### 3.1 近期结果里，VWAP 门槛抬高主要起到了“限流器”作用

从最近三版结果看:

- `VWAP 0.10 -> 0.15 -> 0.16`
- 交易数 `210 -> 157 -> 93`
- 收益 `+92.90% -> +91.34% -> +81.89%`
- 胜率 `79.5% -> 78.3% -> 78.5%`

也就是说:

- `VWAP` 的确能砍单
- 但它没有表现出稳定的胜率提升相关性
- 更像是“削减样本”的阀门，而不是“提高质量”的核心因子

### 3.2 当前对 VWAP 的更合理定位

现阶段更合理的定位应是:

1. `VWAP` 继续保留偏离硬否决能力
2. 但不要再把它当作主要收益优化抓手
3. 不要再靠提高 `min_vwap_score_for_entry` 来追求更高胜率

对下一轮评审的明确偏好是:

- `min_vwap_score_for_entry` 先回到 `0.10`
- 如 DeepSeek 认为有必要，可以进一步评估是否应该低于 `0.10`
- 重点从 “VWAP 选美” 转向 “RSI-MACD 节奏共振”

## 5. 下一轮真正要优化的对象: RSI 与 MACD 的共振关系

### 5.1 当前问题定义

`MACD` 的问题不是无效，而是天然偏慢。

当前系统如果过度依赖 `MACD` 主导节奏，会出现两类问题:

1. 趋势刚启动时，`MACD` 确认偏晚
2. 趋势衰减时，`MACD` 退出也偏慢

而 `RSI` 的优势正好相反:

1. 对节奏加速和减速更敏感
2. 能更早暴露启动、背离、钝化、回摆

因此下一轮的关键不是“用 RSI 替代 MACD”，而是:

> 让 `RSI` 成为 `MACD` 的节奏修正层，使系统既保留趋势方向感，又获得更快的转折感知。

### 5.2 这次评审想解决的核心矛盾

需要 DeepSeek 重点回答:

1. 如何让 `RSI` 对 `MACD` 的延后做出敏捷补偿
2. 如何避免把 `RSI` 也变成另一个僵硬的同向确认器
3. 当 `RSI` 与 `MACD` 短时矛盾时，如何保留 `RSI` 的预警价值，而不是立刻将其视为噪音

### 5.3 本次对 RSI 的明确设计诉求

下一轮设计必须满足以下原则:

1. `RSI` 不能只是“MACD 同向时再加一点分”的弱附属因子
2. `RSI` 必须能在 `MACD` 还没完全翻转前，提前反映节奏衰减或再启动
3. `RSI` 和 `MACD` 矛盾时，不应简单硬 veto
4. 更合理的用法应是:
   - `RSI` 作为提前减分、提前加分、提前降杠杆或提前限制加仓的节奏因子
   - 而不是单纯把方向不同定义为“禁止交易”

## 6. 建议 DeepSeek 重点评审的问题

请 DeepSeek 重点围绕以下问题给出方案:

### 6.1 门槛层

1. 是否同意把默认门槛从 `0.97 / 0.16` 回退到 `0.85 / 0.10`
2. `VWAP` 是否应进一步降级为“偏离否决器 + 轻微加减分项”
3. 是否应停止把“开仓数压到 90-120”作为当前主目标

### 6.2 RSI-MACD 共振层

1. `RSI` 最适合承担哪一种角色:
   - 启动确认
   - 衰减识别
   - 背离预警
   - 回摆再启动确认
   - 上述角色的组合
2. 当 `MACD` 仍指向原趋势，但 `RSI` 先转弱时:
   - 应该减分
   - 应该降杠杆
   - 应该缩仓
   - 还是只在某些 15m/1h 结构下 veto
3. 如何让 `RSI` 保持“敏捷”，而不是被 `MACD` 的慢节奏完全吞掉

### 6.3 15m / 1h 协同层

1. `15m RSI` 是否应主要负责入场节奏
2. `1h RSI` 是否应主要负责趋势延续健康度
3. `RSI` 是否更适合做:
   - `entry refinement`
   - `attenuation penalty`
   - `position scaling`
   - `exit early warning`
