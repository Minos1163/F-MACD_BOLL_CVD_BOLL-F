# MACD_MTF_Strategy V6 → V7 架构选择建议

> 文档用途：针对"是否替换布林带"的决策分析  
> 核心问题：是否用 CVD+MACD+VWAP 或 EMA+MACD+VWAP 替代当前 BOLL+MACD+VWAP  
> 基线：V6 当前结果 `+6.33%`，最大回撤 `12.86%`，盈利因子 `2.21`

---

## 一、先回答核心问题：建议不替换 BOLL

**结论先行：**

| 方案 | 建议 | 核心理由 |
| --- | --- | --- |
| 回退 EMA | ❌ 不建议 | 已验证 EMA 版本为负收益，BOLL 替换后才转正 |
| 替换为 CVD | ❌ 不建议独立替换 | CVD 是资金流向指标，不能替代结构层，属于不同维度 |
| BOLL + CVD 叠加 | ✅ 建议方向 | CVD 可作为第 5 层过滤，解决当前尾部风险问题 |
| 保持 BOLL 不变 | ✅ 当前最优基础 | BOLL 提供 EMA 不具备的带宽信息，是当前策略正收益的结构基础 |

---

## 二、EMA 方案分析：为什么不应回退

### 2.1 历史已有定论

当前策略的演进路径是：

```
EMA + MACD + VWAP
       ↓ 负收益
BOLL + MACD + VWAP
       ↓ +2.39%
BOLL + MACD + VWAP + A2（子状态筛选）
       ↓ +6.33%
```

EMA 版本的失败不是参数问题，是**结构信息不足**的问题。

### 2.2 EMA 相比 BOLL 缺少什么

| 维度 | EMA | BOLL | 当前策略依赖 |
| --- | --- | --- | --- |
| 趋势方向 | ✅ | ✅ | `1H/4H` 方向判断 |
| 趋势强弱 | ❌ 无带宽概念 | ✅ `1.2x/1.0x/0.6x` | `BOLL multiplier` 分档 |
| 结构上下边界 | ❌ 单线 | ✅ 上中下轨 | `middle_hard_block` |
| 斜率判断 | ✅ | ✅ | `bb_slope` 过滤 |

当前策略中，`BOLL=1.2x` 不仅是一个标签，而是：

- 用来分档仓位（`strong_trend_leverage_mult`）
- 用来做 `flip_bearish` 子状态过滤
- 用来做中轨硬封锁

这些逻辑如果回退到 EMA，需要用复杂的多均线宽度计算来近似，工程成本高且不一定更优。

### 2.3 EMA 的唯一优势场景

EMA 在趋势跟随、穿越类信号中比 BOLL 更简洁，但当前策略的核心信号是**位置判断**（价格相对 VWAP 和结构的关系），不是均线穿越。EMA 在这个用途上本质上是退化版 BOLL。

---

## 三、CVD 方案分析：可以加，但不能替换

### 3.1 CVD 是什么维度的信息

CVD（Cumulative Volume Delta）= 主动买量 - 主动卖量的累积值，反映的是**买卖双方的力量对比**，属于资金流向/订单流维度。

BOLL 是**价格结构维度**，CVD 是**资金行为维度**。

两者是**互补**关系，而不是**替代**关系。

### 3.2 当前策略的真实缺口在哪里

从 V6 的主要亏损单分析：

| symbol | entry_time | pnl | signal_score | vwap_score |
| --- | --- | --- | --- | --- |
| KASUSDT | `2026-02-20 11:15` | `-352.40` | `0.9282` | `0.1507` |
| FILUSDT | `2026-02-11 15:15` | `-120.59` | `0.9482` | `0.1482` |
| TAOUSDT | `2026-02-24 04:15` | `-77.48` | `0.9279` | `0.1504` |

这些单子的特征是：

- 价格结构（BOLL 1.2x）满足
- VWAP 双重压制（`short_dual_pressure`）满足
- 信号分高
- 但仍然立刻被止损

**这说明在入场时，虽然空间结构压制成立，但实际资金买盘力度并未衰减**，导致价格在 bar 内反弹并击穿止损。

这正是 **CVD 可以发挥作用的精准场景**：

> 如果 CVD 显示该时段仍有净买入累积，说明压制结构虽成立，但资金行为并不支持空头成立。

### 3.3 CVD 作为第 5 层过滤的工作逻辑

建议加法：在 `short_dual_pressure` 已通过所有现有过滤层后，增加 CVD 否决条件：

```
信号候选（short_dual_pressure）
        ↓
CVD 状态检查
  ├── CVD_delta（当前 bar）< 0（主动卖压 > 买压）       → 放行
  ├── CVD_slope（近 N bar）趋势向下                     → 放行
  ├── CVD_delta > 0 且 slope 向上（明确净买入）         → 否决
  └── CVD 中性                                          → 降低仓位加成或不加
```

这个逻辑不替换任何现有层，而是在 `short_dual_pressure` 已通过之后，增加一道"资金行为与价格结构一致性"验证。

## 四、CVD 引入的设计建议

### 4.1 CVD 指标计算建议

| 维度 | 推荐方案 |
| --- | --- |
| 时间框架 | 优先使用 `1H` CVD（与主信号时间框架一致） |
| 计算方式 | `CVD_delta = 当前 bar 主买量 - 主卖量` |
| 趋势维度 | `CVD_slope_N = 近 N 根 bar 的 CVD_delta 累积斜率`（建议 N=3~5） |
| 阈值 | 以 0 为分界，不需要精确数值，只需方向性判断 |

### 4.2 CVD 过滤参数建议

```json
"use_cvd_filter": true,
"cvd_filter_scope": ["short_dual_pressure"],
"cvd_1h_slope_lookback": 3,
"cvd_1h_block_on_positive_slope": true,
"cvd_1h_reduce_on_neutral": true,
"cvd_neutral_position_multiplier": 0.7
```

### 4.3 CVD 过滤与当前参数的联动方式

建议不作为独立评分项，而是作为**入场后仓位调节器**：

| CVD 状态 | 建议处理方式 |
| --- | --- |
| CVD 净卖出，斜率向下 | 正常开仓，允许 `dual_pressure_bonus` |
| CVD 中性 | 正常开仓，`bonus` 降为 0 或减半 |
| CVD 净买入，斜率向上 | 直接否决 `short_dual_pressure` 入场 |

## 五、三种架构的综合对比

| 架构 | 结构层 | 资金流层 | 已验证 | 预期效果 |
| --- | --- | --- | --- | --- |
| `EMA + MACD + VWAP` | 弱（单线） | 无 | 负收益 | ❌ 不考虑 |
| `BOLL + MACD + VWAP`（当前） | 强（带宽+轨道） | 无 | +6.33% | 当前基准 |
| `BOLL + MACD + VWAP + CVD`（建议） | 强（带宽+轨道） | 新增 | 未验证 | 预计降低大亏单频率 |

## 六、引入 CVD 的预期影响

### 6.1 针对大亏单

KASUSDT、FILUSDT、TAOUSDT 这 3 笔最大亏损单，都属于"结构成立但资金行为反向"的典型场景。CVD 否决可能直接过滤这类单子，对应减少亏损约 `$550`。

但需要注意：CVD 过滤也可能过滤掉部分盈利单，净效果需回测确认。

### 6.2 对交易数量的影响

若以 CVD 为硬过滤条件（中性或净买入时否决），当前 52 笔 `short_dual_pressure` 交易中，预计过滤比例在 `20%~35%`，实际成交笔数可能降至 `33~42` 笔。

这是可接受的代价，前提是被过滤掉的以亏损单为主。

### 6.3 对盈利因子的预期

若 CVD 过滤有效：

- 大亏单减少 → 盈利因子从 2.21 提升至 2.5~3.0
- 交易笔数小幅下降但胜率可能提升至 78~82%

---

## 七、建议的验证步骤

1. **先不改现有代码**，在历史数据上提取 CVD 数据，手工验证 3 笔大亏单在入场时的 CVD 状态

2. 若 3 笔大亏单均为 CVD 净买入或中性，则 CVD 过滤方向成立，开始实现

3. 实现 CVD 计算层后，先以**只记录不阻断**的模式回测，观察哪些单子会被过滤

4. 确认过滤结构合理后，切换为硬过滤，对比完整回测结果

5. 若 CVD 引入后盈利因子 ≥ 2.5 且回撤低于 10%，则 CVD 层正式纳入策略

---

## 八、最终决策建议

```
不回退 EMA
不用 CVD 替换 BOLL
↓
保留 BOLL 作为结构层（当前最优）
↓
在 short_dual_pressure 层叠加 CVD 资金流过滤
↓
同时推进 D 的分档加仓优化
↓
V7 = BOLL + MACD + VWAP + CVD（第5层）+ 分档 D
```

**核心逻辑：** 当前策略的失败案例不是"结构判断错了"，而是"结构成立但资金行为不配合"。CVD 的作用是补全这个维度，而不是重构框架。
