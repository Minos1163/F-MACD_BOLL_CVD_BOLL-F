## 一、系统总框架

### 核心逻辑链

```
大周期（4H）选方向
  ↓
主操作周期（1H）等结构企稳          ← 新增关键层
  ↓
触发层（15m）等回踩信号
  ↓
执行层（5m）捕捉精准入场点
  ↓
盈利后分批加仓
  ↓
动能转弱规则化出场
```

### 执行口诀

```
4H 告诉你能做什么方向
1H 告诉你现在能不能做
15m 告诉你大概在哪里做
5m 告诉你精确的触发点
```

### 七步执行顺序

1. 选方向（4H）
2. 等结构（1H）
3. 找机会（15m）
4. 精准入场（5m）
5. 控风险（止损）
6. 做加仓（盈利后）
7. 规则出场（止盈/移止）

## 三、第一步：4H 定方向

**没有 4H 方向，不做任何交易。**

### 做多条件（满足 4 条中至少 3 条）

```
□ 价格 > EMA55
□ EMA21 > EMA55
□ MACD 柱子 > 0
□ 价格 > Anchored VWAP
```

**强多结构**（优先做多）：

```
价格 > EMA21 > EMA55 > EMA200
```

### 做空条件（满足 4 条中至少 3 条）

```
□ 价格 < EMA55
□ EMA21 < EMA55
□ MACD 柱子 < 0
□ 价格 < Anchored VWAP
```

**强空结构**（优先做空）：

```
价格 < EMA21 < EMA55 < EMA200
```

### 4H 方向不明确时

以下情况出现，**禁止交易**，等待方向明朗：

- 价格在 EMA21 与 EMA55 之间横盘震荡
- MACD 在零轴附近长时间钝化
- 多空条件均未达到 3/4 满足

## 四、第二步：1H 主操作层（新增核心）

> 这是 v2.0 的关键新增层。1H 是连接 4H 方向与 15m 入场的枢纽，负责**结构确认、止损锚定、加仓基准**三项核心功能。

### 1H 的三个核心功能

**① 结构过滤器**

4H 做多背景下，1H 必须同样维持多头结构。若 1H 仍在主动下跌，15m 出现的所有金叉均视为陷阱信号，等待 1H 动能先停下来再操作。

**② 止损锚点**

主止损锚定 **1H 关键结构低点**下方，而非 15m 低点。1H 止损更宽，不易被短期波动扫掉，适合趋势持仓。

**③ 加仓基准**

第二笔确认仓等待 **1H 层面结构突破**（1H 前高突破 + VWAP 站稳 + 量能放大），而非仅看 15m 小高点突破，加仓胜率更高。

### 1H 做多等待形态

```
□ 价格回踩 1H EMA21 不破
□ 回踩到 1H VWAP 附近获得支撑
□ 1H MACD 红柱缩短后停止缩短
□ 1H 成交量在回踩时明显缩减
```

以上信号说明：**1H 结构企稳，可以进入下一步**。

### 1H 做空等待形态

```
□ 价格反弹至 1H EMA21 附近遇阻
□ 反弹至 1H VWAP 下方受压
□ 1H MACD 绿柱缩短后停止缩短
□ 1H 反弹成交量明显萎缩
```

### 1H 时间止损（新增）

```
进场后 3～5 根 1H K 线仍未启动
→ 减仓 50% 或直接清仓
```

**逻辑**：真正强趋势不会长时间磨底，超时不动说明判断有误，需要重新评估。

## 五、第三步：15m 触发层

**4H 方向明确 + 1H 结构企稳**之后，用 15m 确认具体回踩质量。

### 理想做多回踩形态

```
□ 价格回踩 15m EMA21 或 VWAP
□ 15m MACD 红柱缩短（但未死叉）
□ 回调成交量明显缩减
□ 出现以下任一 K 线形态：
   - 小阴线缩量收盘
   - 十字星（多空均衡）
   - 明显下影线（有承接）
   - 多根小 K 线横盘收敛
```

以上信号说明：**回调接近尾声，做多机会成熟**。

### 理想做空反弹形态

```
□ 价格反弹至 15m EMA21 或 VWAP 下方
□ 15m MACD 绿柱缩短（但未金叉）
□ 反弹成交量明显缩减
□ 出现上影线 / 小阳缩量 / 横盘受压形态
```

## 六、第四步：5m 精准入场

**不要只看 15m**，等 5m 或 1m 给出触发信号再入场。

### 最优做多入场：四层共振

```
4H 多头结构  ✓
    +
1H EMA21 支撑企稳  ✓
    +
15m 回踩缩量出现承接  ✓
    +
5m MACD 金叉  ✓
= 最高质量入场，开首仓 40%
```

缺少任一层：降低首仓比例至 20%，或继续等待。

### 5m 做多入场触发（满足任一组合）

```
组合 A：5m MACD 金叉 + 价格站上 VWAP
组合 B：5m MACD 柱子翻红 + 放量突破 15m 小结构高点
组合 C：5m 价格有效突破 15m 关键小高点（带量）
```

### 5m 做空入场触发（满足任一组合）

```
组合 A：5m MACD 死叉 + 价格跌回 VWAP 下方
组合 B：5m MACD 柱子翻绿 + 跌破 15m 小结构低点
组合 C：5m 价格有效跌破 15m 关键小低点（带量）
```

## 七、仓位管理

**绝不一把梭，分三笔建仓。**

### 仓位分配

| 仓位 | 比例 | 入场时机 | 止损参考 |
|------|------|----------|----------|
| 首仓 | 40% | 5m 入场信号触发 | 1H 关键结构低点 |
| 确认仓 | 30% | 突破 1H 小结构高点 + MACD 放大 | 提至开仓价附近 |
| 加速仓 | 30% | 主升/跌浪加速 + 1H 突破前高 | 沿 1H EMA21 移动 |

### 仓位管理的好处

- 第一次看错：亏损控制在 40% 仓位的单笔止损内
- 看对方向：三笔仓位叠加，利润最大化
- 心态更稳：不因满仓而情绪化止损

## 八、止损系统

### 做多止损：双层参考

**首选（1H 结构止损）**

```
止损位 = 1H 最近关键结构低点下方
```

比 15m 止损更宽，不易被短期插针扫掉。

**次选（EMA 止损）**

```
止损位 = 1H EMA55 下方
```

适合趋势明确时的宽幅持仓。

**紧急参考（15m 结构止损）**

```
止损位 = 15m 最近回踩低点下方
```

仅用于短线入场，波段持仓不推荐。

### 做空止损

```
止损位 = 1H 最近关键结构高点上方
```

### 时间止损（强制执行）

| 场景 | 处理方式 |
|------|----------|
| 进场后 3～5 根 1H K 线未启动 | 减仓 50% 或清仓 |
| 进场后 5 根 15m K 线未启动 | 减仓观察 |
| 方向与预期持续背离 | 立即止损，不等待 |

## 九、加仓规则

**只允许盈利后加仓，亏损状态下绝不加仓。**

### 第一次加仓（确认仓 30%）

满足以下全部条件：

```
□ 首仓已有浮盈
□ 价格突破 1H 小结构前高（新增：以 1H 为准）
□ 1H MACD 红柱继续扩大
□ 价格在 1H VWAP 上方
□ 成交量有所放大
```

### 第二次加仓（加速仓 30%）

满足以下信号出现：

```
□ 出现三次启动模型的第三次启动
□ 回踩比前次更浅（低点抬高）
□ 1H EMA21 支撑更强
□ 1H MACD 红柱继续扩大
□ 出现加速放量突破
```

### 禁止加仓的情况（任一出现即禁止）

```
✗ 当前仓位处于亏损状态
✗ 价格离 1H EMA21 距离过远（超过 2%）
✗ 1H 出现连续 3 根以上大阳/阴
✗ 成交量未有效放大
✗ MACD 虽创新高但价格推进明显变弱（顶背离风险）
✗ 距前高/阻力位不足 1%
```

## 十、出场系统

**出场必须规则化，赚到的利润不能靠情绪守住。**

### 第一类：分批止盈

适合 BTC 短中波段：

| 目标 | 减仓比例 | 动作 |
|------|----------|------|
| +1% ～ +1.5% | 减 1/3 | 锁定初步利润 |
| +2% ～ +3% | 再减 1/3 | 锁定主要利润 |
| 超过 +3% | 剩余让跑 | 移动止损跟踪 |

### 第二类：结构位止盈

到以下位置时主动减仓：

```
□ 4H / 1H 前高（关键阻力）
□ 前期密集成交区（压力明显）
□ 整数关口附近（市场心理位）
□ Anchored VWAP 上方显著偏离（均值回归风险）
```

### 第三类：动能衰减止盈（信号出现即减仓）

```
□ 1H MACD 红柱开始缩短
□ 15m / 5m 出现明显顶背离
□ 放量冲高后快速回落（缩量无法跟进）
□ 1H 价格跌破 EMA21（清仓信号）
```

## 十一、移动止损

**单子走顺后，止损必须及时上移，保护既得利润。**

### 做多移动止损三阶段

**阶段 1：保本**

```
触发：首仓浮盈 ≥ +0.5%
操作：止损提至开仓价（保本止损）
目的：消除亏损可能，进入无风险持仓状态
```

**阶段 2：锁利**

```
触发：1H 形成新的低点抬高（第一次回踩不破）
操作：止损提至 1H 前一个结构低点下方
目的：锁住部分利润，给行情呼吸空间
```

**阶段 3：跟踪**

```
触发：进入主升浪（价格加速，量能放大）
操作：沿 1H EMA21 动态上移止损
目的：让利润最大化奔跑，直至趋势结束
```

### 做空移动止损（对称操作）

```
阶段 1：止损降至开仓价（保本）
阶段 2：止损降至 1H 前一结构高点上方
阶段 3：沿 1H EMA21 动态下移
```

## 十二、完整执行流程

### 标准做多流程

```
Step 1 ── 4H 确认方向
         价格 > EMA55，MACD > 0，价格 > Anchored VWAP
         满足 ≥3 条 → 方向：做多

Step 2 ── 1H 等待结构企稳（核心步骤）
         回踩 1H EMA21 或 VWAP 获支撑
         1H MACD 红柱停止缩短
         量能缩减 → 等待进入下一步

Step 3 ── 15m 确认回踩质量
         15m 回踩 EMA21，MACD 缩短
         出现 K 线承接形态
         成交量缩减 → 回踩信号确认

Step 4 ── 5m 精准入场
         MACD 金叉 or 柱子翻红
         价格站上 5m VWAP
         → 开首仓 40%，止损 = 1H 结构低点下方

Step 5 ── 第一次加仓
         价格突破 1H 小结构高点
         1H MACD 放大 + 量能跟上
         → 加仓 30%，止损上移至开仓价

Step 6 ── 第二次加仓
         主升浪加速，放量突破
         1H 突破前高
         → 加仓 30%，止损沿 1H EMA21 移动

Step 7 ── 分批出场
         +1% 先减 1/3
         到 1H/4H 前高再减 1/3
         剩余仓位沿 1H EMA21 移动止损，直至离场
```

### 标准做空流程

```
Step 1 ── 4H 确认空头方向（满足 ≥3 条）
Step 2 ── 1H 等待反弹结构受压（反弹到 EMA21/VWAP 下方被拒绝）
Step 3 ── 15m 确认反弹缩量（绿柱缩短，K 线受压）
Step 4 ── 5m 死叉或跌破小结构低点 → 开首仓 40%
Step 5 ── 跌破 1H 小结构低点 + MACD 放大 → 加仓 30%
Step 6 ── 主跌浪加速 + 量能放大 → 加仓 30%
Step 7 ── 分批止盈，沿 1H EMA21 下移止损直至离场
```

## 十三、信号过滤规则

### 这套系统只做

```
✓ 4H 趋势方向明确（≥3/4 条件满足）
✓ 1H 结构回踩后企稳（新增必要条件）
✓ 15m 回踩缩量，结构良好
✓ 上涨量 > 回调量（做多时）
✓ 四层周期方向一致
```

### 这套系统不做

```
✗ 4H 横盘区间的中间位置
✗ 1H 与 4H 方向出现明显冲突
✗ 15m 连续大阳/大阴后的追单
✗ MACD 已远离零轴后的后排进场
✗ 无成交量配合的假突破
✗ 价格离 VWAP/EMA 偏差超过 2%
```

### 附加过滤规则（高价值）

**规则 1：量价配合**

做多时必须满足：上涨量 > 回调量。否则趋势质量差，降低仓位或放弃。

**规则 2：不追大 K 线**

大阳/大阴出现后，至少等一次回踩才考虑入场。

**规则 3：远离均线不追**

价格偏离 1H EMA21 超过 2% 时，不做追多/追空，等回踩。

**规则 4：周期冲突时等待**

4H 多头 + 1H 强空 → 等，不硬做任何方向。

## 十四、常见错误清单

### 入场类错误

```
□ 4H 没有明确趋势时强行入场
□ 1H 未企稳就根据 15m 信号入场（v1.0 的主要缺陷）
□ 15m 没有回踩就直接追涨/追跌
□ MACD 金叉后不看位置直接冲
□ 不等 5m/1m 与上层周期共振确认
```

### 仓位类错误

```
□ 第一笔就满仓（无法加仓，心态崩）
□ 亏损状态下继续加仓摊薄
□ 多次信号共振后仍只开小仓（利润做不大）
```

### 出场类错误

```
□ 第一笔浮盈就全平（利润做不大）
□ 情绪化止盈（涨一点就跑，跌一点就割）
□ MACD 缩短的信号出现后仍不减仓
□ 没有使用移动止损（利润吐回去）
□ 靠感觉而非规则决定出场时机
```

## 十五、复盘模板

**每笔单子结束后必须完成，连续复盘 30 笔可显著提升系统成熟度。**

### 入场质量评估

```
[ ] 4H 方向是否清晰（满足 ≥3/4 条件）
[ ] 1H 是否有有效的结构企稳形态
[ ] 15m 是否是真实回踩（缩量 + K 线承接）
[ ] 5m 入场是否与 1H/15m 形成共振
[ ] 成交量是否全程配合（量价关系健康）
```

### 风险管理评估

```
[ ] 首仓止损是否锚定 1H 结构（而非随意设置）
[ ] 止损距离是否合理（不过宽、不过窄）
[ ] 1H 时间止损规则是否有执行
[ ] 是否在亏损状态下有过加仓行为
```

## 十六、v1.0 vs v2.0 对比说明

> 供专家组讨论：本次重构的核心变化与逻辑依据

### 主要变化对比

| 维度 | v1.0（原版） | v2.0（重构版） |
|------|-------------|---------------|
| 周期层级 | 4H → 15m → 5m | 4H → **1H** → 15m → 5m |
| 主操作周期 | 15m | **1H** |
| 入场前提 | 4H 趋势 + 15m 回踩 | 4H 趋势 + **1H 企稳** + 15m 回踩 |
| 止损锚定 | 15m 结构低点 | **1H 结构低点**（更宽更稳健） |
| 加仓基准 | 15m 小高点突破 | **1H 结构突破**（胜率更高） |
| 移动止损 | 沿 15m EMA21 | **沿 1H EMA21**（更少干扰） |
| 时间止损 | 3～5 根 15m | **3～5 根 1H**（更合理的等待） |

### 引入 1H 的核心逻辑

**问题（v1.0）**：4H 方向与 15m 入场之间跨度太大（4小时 vs 15分钟），在错误的 1H 位置入场是主要亏损来源。

**解决方案（v2.0）**：
1. 4H 判断能做什么方向
2. **1H 判断现在能不能做**（结构企稳是入场前提）
3. 15m 判断回踩质量
4. 5m 精准入场

**实际意义**：
- 即使 4H 是多头，1H 若仍在主动下跌，所有 15m 金叉均为假信号
- 1H 止损比 15m 止损宽约 3-5 倍，大幅降低被扫止损的概率
- 以 1H 结构突破为加仓依据，每次加仓都有充分的结构支撑

### 待讨论议题

1. **1H 企稳的判断标准** — 当前定义为"MACD 红柱停止缩短"，是否需要更严格的量化条件？
2. **跨周期冲突处理** — 4H 多头 + 1H 空头时，等待的标准时间窗口如何定义？
3. **1H 止损宽度** — 不同波动环境下（牛市/熊市/震荡），1H 结构止损的平均距离是否需要动态调整？
4. **仓位比例** — 40/30/30 的分配是否适合不同波动率环境，是否需要分情况讨论？
5. **适用性边界** — 本系统在极端行情（单边加速、黑天鹅）下的应对规则是否需要补充？
