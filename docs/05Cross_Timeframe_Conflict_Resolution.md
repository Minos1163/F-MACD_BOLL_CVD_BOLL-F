## 一、理解冲突的本质

### 冲突为何发生

4H 多头 + 1H 空头不是一个"错误信号"，而是趋势运行中完全正常的中间状态，有两种根本来源：

**来源 A：正常回调（冲突是暂时的）**

大级别（4H）趋势仍在延续，但中级别（1H）正在经历健康的回调修复。此时 1H 的"空头"是暂时的、有限度的，属于 4H 趋势的一部分。

```
4H 上涨趋势
       ↑
       │  ← 4H 多头
       │
  1H 回调  ← 1H 短暂空头（正常现象）
       │
       ↑ 1H 恢复多头后继续上涨
```

这种冲突的正确处理：等待 1H 回调结束，在 1H 重新企稳后入场做多。

**来源 B：趋势转折前兆（冲突可能持续）**

4H 趋势正在减弱，1H 已经率先转向，这是更大级别转折的早期信号。此时贸然做多可能正好接在顶部。

```
4H 上涨趋势减弱中
       ↑ ←（涨速放缓，MACD 顶背离）
       │
  1H 提前转空  ← 先行信号
       ↓
  4H 随后转空
```

这种冲突的正确处理：不入场，等待判断明朗，或接受做空机会。

### 核心判断原则

> 跨周期冲突的本质问题只有一个：**这次 1H 空头是 4H 趋势中的回调，还是 4H 趋势转折的前兆？**

所有的判断标准、等待窗口、解除路径，都是为了回答这一个问题。

## 二、冲突强度分级标准

不是所有的跨周期冲突都需要同等对待。首先量化冲突的强度，再决定等待时长和处理方式。

### 冲突强度评分（满分 12 分）

| 评估维度 | 弱冲突（0分） | 中冲突（1分） | 强冲突（2分） |
|----------|-------------|-------------|-------------|
| 1H MACD 位置 | 红柱缩短（回调） | 零轴附近钝化 | 绿柱扩大（趋势反转） |
| 1H 价格与 EMA55 关系 | 价格在 EMA55 上方 | 触碰 EMA55 | 收盘于 EMA55 下方 |
| 1H 下跌持续时间 | ≤ 3 根 1H K 线 | 4 ～ 7 根 1H K 线 | ≥ 8 根 1H K 线 |
| 1H 下跌幅度（相对 ATR） | < 1.5 × ATR | 1.5 ～ 3.0 × ATR | > 3.0 × ATR |
| 4H MACD 状态 | 红柱仍在扩大 | 红柱开始缩短 | 顶背离或接近死叉 |
| 1H 成交量变化 | 下跌缩量（健康） | 下跌量平 | 下跌放量（主动抛售） |

**冲突强度判定：**

```
总分 0 ～ 3 分  →  弱冲突（轻度回调，可缩短等待窗口）
总分 4 ～ 7 分  →  中冲突（标准回调，执行标准等待窗口）
总分 8 ～ 12 分 →  强冲突（潜在转折，延长等待或放弃做多）
```

## 三、四种典型冲突形态

根据历史出现频率和处理逻辑，跨周期冲突主要分为四种形态。

### 形态一：1H 短期回调型（最常见）

**特征：**

```
4H：方向完全明确，满足 ≥ 4/4 多头条件
1H：价格回踩至 EMA21 附近，MACD 红柱缩短但未死叉
1H 回调持续时间：3 ～ 5 根 K 线
回调幅度：< 2 × ATR(14)
成交量：回调缩量
```

**冲突强度：** 弱（0 ～ 3 分）

**处理方式：** 这是系统最理想的入场前奏，1H 的"空头"只是正常的 1H 企稳打分流程中的等待阶段，并非真正意义的冲突。

**等待内容：** 按标准 1H 企稳打分流程等待，得分 ≥ 70 分即可入场，无需特殊处理。

---

### 形态二：1H 深度回调型（需要重点处理）

**特征：**

```
4H：方向仍然明确，但 MACD 红柱开始缩短
1H：价格已跌破 EMA21，在 EMA55 附近寻找支撑
1H 回调持续时间：5 ～ 8 根 K 线
回调幅度：2 ～ 3 × ATR(14)
成交量：下跌量能略有放大
```

**冲突强度：** 中（4 ～ 7 分）

**处理方式：** 真正需要"等待时间窗口"的场景。需要等待 1H 在 EMA55 获得支撑并重新企稳，同时监控 4H MACD 是否继续恶化。

**等待内容：** 见第四章标准等待窗口定义。

---

### 形态三：1H 趋势反转型（危险区域）

**特征：**

```
4H：MACD 出现顶背离，或红柱已开始明显缩短
1H：价格已跌破 EMA55，MACD 形成绿柱并扩大
1H 下跌持续时间：> 8 根 K 线
回调幅度：> 3 × ATR(14)
成交量：下跌明显放量
```

**冲突强度：** 强（8 ～ 12 分）

**处理方式：** 此时 4H 多头信号正在被破坏，做多风险极高。有两个选项：

- 选项 A：放弃做多，等待 4H 方向重新确认后再操作
- 选项 B：等待 1H 形成第一个做空机会（4H 即将转空，1H 先行做空）

**等待内容：** 见第五章路径三（冲突升级处理）。

---

### 形态四：周期割裂型（最难处理）

**特征：**

```
4H：恰好满足 3/4 多头条件（边缘状态）
1H：方向明确偏空，MACD 绿柱持续 > 5 根
两个周期的信号强度都不够明确
```

**冲突强度：** 中到强（6 ～ 10 分）

**处理方式：** 周期割裂意味着市场本身尚未形成方向共识，任何方向的交易胜率都不高。

**唯一正确答案：** 不做，等待两个周期方向趋于一致。参见第四章的最长等待窗口设置。

## 四、等待窗口的量化定义

等待窗口解决的核心问题是：**最多等多久？等到什么程度才放弃？**

### 等待窗口的三个维度

等待窗口由三个维度共同定义，任何一个维度超出上限，均视为等待失效：

```
维度 1：时间上限（最多等待多少根 1H K 线）
维度 2：价格下限（1H 下跌到什么位置就放弃）
维度 3：动能上限（4H MACD 恶化到什么程度就放弃）
```

### 按冲突强度划分的等待窗口

#### 弱冲突（0 ～ 3 分）等待窗口

```
时间上限：5 根 1H K 线（约 5 小时）
价格下限：1H EMA55 下方 0.3%（不得破此位）
动能上限：4H MACD 红柱缩短幅度 < 30%
```

**等待判定：** 在窗口内出现 1H 企稳信号（打分 ≥ 70）即入场；超出任一上限即放弃本次机会，等下一个设置。

---

#### 中冲突（4 ～ 7 分）等待窗口

```
时间上限：8 根 1H K 线（约 8 小时）
价格下限：4H EMA55 下方 0.5%（大级别结构底线）
动能上限：4H MACD 红柱缩短幅度 < 50%，且未出现死叉迹象
```

**等待判定：**
- 窗口内 1H 企稳打分 ≥ 75（比正常高 5 分，冲突环境要求更严格）→ 首仓 20%（比正常减半）
- 超出时间或价格上限 → 放弃做多，进入观察模式
- 超出动能上限 → 考虑路径三（转为做空准备）

---

#### 强冲突（8 ～ 12 分）等待窗口

```
时间上限：3 根 4H K 线（约 12 小时）
价格下限：4H EMA200 下方 0.5%（系统性底线）
动能上限：4H MACD 红柱缩短幅度 < 70%，未形成死叉
```

**等待判定：**
- 窗口内 4H 方向重新确认（重新满足 4/4 多头条件）且 1H 重新企稳 → 首仓 15%（极度保守）
- 任何上限触发 → 完全放弃做多方向

---

### 等待窗口的核心逻辑

```
冲突越强 → 等待时间越短（市场快速验证判断是否正确）
冲突越强 → 解除标准越严（需要更多证据才能入场）
冲突越强 → 首仓越小（即使入场也要控制初始风险）
```

这三条逻辑保证了：即使在跨周期冲突场景下频繁操作，单次判断失误的代价也在可控范围内。

## 五、冲突解除的三条路径

冲突不一定需要通过"等待"来解除，有三条截然不同的路径，对应三种截然不同的市场结果。

### 路径一：1H 顺势恢复（冲突正常解除）

**定义：** 1H 在等待窗口内完成回调，重新建立多头结构，与 4H 方向重新一致。

**触发标准（须全部满足）：**

```
□ 1H 价格重新站上 EMA21，且收盘于 EMA21 上方
□ 1H MACD 红柱重新出现（死叉后金叉，或绿柱缩至接近零轴）
□ 1H 企稳打分 ≥ 70 分（弱冲突）或 ≥ 75 分（中冲突）
□ 1H 成交量在反弹时放大，回调时缩量（量价健康）
□ 4H MACD 状态未继续恶化（红柱缩短幅度在上限内）
```

**入场动作：**

| 冲突强度 | 首仓比例 | 止损设置 | 加仓条件 |
|----------|----------|----------|----------|
| 弱冲突 | 40%（标准） | ATR × 1.5 | 标准条件 |
| 中冲突 | 20%（减半） | ATR × 1.2 | 需额外等 1H 突破前高 |
| 强冲突 | 15%（极保守） | ATR × 1.0 | 仅在 4H 重新满足 4/4 后加仓 |

---

### 路径二：方向等待超时（冲突未解除）

**定义：** 等待窗口内，1H 既未恢复多头，也未进一步明确转空，方向不明朗。

**触发条件（满足任一）：**

```
时间触发：等待根数超过上限（弱 5 根 / 中 8 根 / 强 12H）
价格触发：1H 价格触碰对应等待窗口的价格下限
动能触发：4H MACD 红柱缩短幅度触碰动能上限
```

**处理动作：**

```
Step 1：放弃本次做多机会（不降低标准强行入场）
Step 2：将该价格区域标记为"冲突区"
Step 3：等待市场走出冲突区后重新评估
Step 4：如果价格最终向上突破冲突区高点，可视为新的入场机会，重新走标准流程
```

**等待解锁条件（满足全部后重新进入标准流程）：**

```
□ 价格有效突破冲突期间的最高点（收盘价突破，非插针）
□ 4H MACD 方向恢复，红柱重新扩大
□ 1H 企稳打分重新 ≥ 70 分
```

---

### 路径三：方向升级转空（冲突演变为反向机会）

**定义：** 4H 方向在等待过程中开始动摇甚至转向，1H 的空头不再是回调，而是先行指引信号，出现了做空机会。

**识别标准（强冲突时重点监控，满足 ≥ 3/4 即考虑转空）：**

```
□ 4H MACD 出现顶背离（价格未创新高，MACD 却创新低）
□ 4H 价格跌破 EMA21（4H 多头结构第一道防线）
□ 1H 出现连续 3 根以上下跌 K 线，且每根均在 EMA55 下方收盘
□ 1H 做空条件满足 ≥ 3/4（系统空头信号出现）
```

**处理动作：**

```
不再等待做多信号的解除
转为做空方向的标准流程
按照 4H 空头 + 1H 主操作周期的系统逻辑操作
首仓保守为正常空单的 50%（因为 4H 仍未完全确认转空）
```

**追踪逻辑：**

路径三是三条路径中最有价值的一条，因为在方向转折的早期介入做空，往往能获得最大的利润空间。但它也是最危险的一条——在方向尚未完全确认时做空，止损设置至关重要。

```
路径三止损设置：
做空止损 = 冲突期间最高价 + ATR × 1.5

这个止损兼顾两层含义：
  1. 若价格回到冲突区高点上方，说明 4H 多头尚未破坏，做空错误
  2. ATR × 1.5 的缓冲防止高点处的刷新插针导致被扫
```

## 六、等待期间的主动观察清单

等待不是被动地盯着屏幕，而是主动收集支持或否定"4H 趋势延续"的证据。

### 每根 1H K 线收盘后检查

**支持 4H 趋势延续的信号（加分项）：**

```
[ ] 本根 1H K 线是否出现下影线承接（下影 > 实体 × 1.5）
[ ] 本根 1H K 线成交量是否相对前根缩减（回调缩量）
[ ] 1H MACD 绿柱是否在缩短（空头动能衰减）
[ ] 1H 价格是否仍在 4H EMA21 上方（大级别支撑有效）
[ ] 链上数据是否无异常（无巨量转出或交易所大额流入）
```

出现 ≥ 3 项 → 继续等待，趋势延续概率高。

**否定 4H 趋势延续的信号（减分项）：**

```
[ ] 1H 下跌 K 线是否持续放量（主动抛售）
[ ] 1H MACD 绿柱是否在持续扩大
[ ] 价格是否已跌破 4H EMA21
[ ] 4H MACD 红柱是否出现明显缩短（> 40%）
[ ] 是否出现 4H 级别的顶背离信号
```

出现 ≥ 3 项 → 考虑启动路径三评估，不再等待路径一解除。

---

### 每根 4H K 线收盘后重新评估

4H K 线收盘是重新评估整体冲突强度的时机。

**重新评分流程：**

```
Step 1：按照第二章的冲突强度评分表重新打分
Step 2：比较新分数与最初评分的变化方向
  → 分数下降：冲突在缓解，继续等待路径一
  → 分数持平：不确定，延长观察
  → 分数上升 ≥ 3 分：冲突在加剧，考虑放弃或启动路径三
Step 3：确认当前是否仍在等待窗口时间上限内
```

## 七、特殊情况处理

### 特殊情况 1：1H 持续创新低但 4H 仍强势

**场景描述：** 1H 持续下跌且不断创新低，但 4H 的 EMA 排列和 MACD 仍然非常强劲。

**判断逻辑：**

这种情况通常发生在 1H 的强力洗盘阶段，目的是清除浮筹。特征是下跌快速、成交量缩减、没有明显的主动卖盘。

**处理方式：**

```
若成交量缩减 + 1H 下跌速度在放缓：
  等待 1H 出现第一根企稳 K 线（下影线 / 十字星）
  以此作为等待窗口的起点重新计时

若成交量放大 + 1H 持续加速下跌：
  不等待，视为否定信号，冲突强度升级
  进入路径二或路径三评估
```

---

### 特殊情况 2：等待窗口即将超时，1H 显示微弱企稳迹象

**场景描述：** 时间窗口还剩 1～2 根 K 线，1H 出现了初步企稳信号但打分仅 60 分，未达门槛。

**判断逻辑：**

这是最考验执行纪律的场景。降低标准入场是最常见的错误。

**处理方式：**

```
不降低标准（60 分 < 70 分门槛，不入场）
记录该位置为"关注区"
等待窗口超时后，放弃本次机会
观察价格后续行为：
  若价格从当前位置向上突破 → 记为"错过机会"，接受
  若价格继续下跌 → 确认当时不入场的正确性，建立纪律信心
```

> 核心原则：一次降低标准的入场，比十次错过机会的代价更大。

---

### 特殊情况 3：同一交易日内多次出现冲突

**场景描述：** 同一天内，4H 多头 + 1H 空头的冲突出现了两次以上，反复等待反复超时。

**处理方式：**

```
当天停止做多方向的所有操作
进入日内复盘模式，思考：
  这是否说明 4H 趋势本身正在减弱？
  是否应当将 4H 多头的评分重新核实？

单日内冲突超过 2 次 → 降低 4H 方向确信度评级
  原本 4/4 满足 → 降为"3/4 满足边缘状态"
  对应等待窗口切换为"强冲突"模式
```

---

### 特殊情况 4：重要数据发布 / 宏观事件窗口

**场景描述：** 在跨周期冲突等待期间，临近美联储决议、CPI 数据、重大链上事件等。

**处理方式：**

```
事件发布前 2 小时：暂停所有等待窗口的倒计时
事件发布后：
  若行情方向与 4H 多头一致（上涨） → 冲突重新评分，从低级别重新开始等待
  若行情方向加速下跌 → 视情况升级冲突强度，考虑路径三
  若行情大幅波动后回归 → 等待波动率回落至正常水平再重新启动
```

## 八、冲突判断决策树

用于 30 秒内快速判断当前冲突的处理方式。

```
发现 4H 多头 + 1H 空头
         ↓
[Q1] 1H 空头持续了多少根 K 线？

  ≤ 3 根  →  [形态一]  →  弱冲突
                           按标准 1H 企稳打分流程等待
                           窗口：5 根 1H K 线

  4 ～ 7 根  →  [Q2] 1H 价格是否仍在 EMA55 上方？

               是  →  中冲突
                      标准等待窗口
                      窗口：8 根 1H K 线

               否  →  [Q3] 4H MACD 红柱缩短是否 > 40%？

                       否  →  中冲突（偏强）
                              等待窗口缩短 30%
                              首仓降至 20%

                       是  →  强冲突
                              等待窗口：3 根 4H K 线
                              开始路径三评估

  ≥ 8 根  →  [Q4] 4H 是否出现顶背离或 EMA21 跌破？

               否  →  强冲突（但 4H 未破坏）
                      极度保守等待
                      首仓 15%，标准门槛 ≥ 80 分

               是  →  [形态三]  →  放弃做多
                                   评估路径三（转空机会）
```

## 九、实战执行清单

### 发现跨周期冲突时（立即执行）

```
[ ] Step 1：按第二章公式计算冲突强度分数（0 ～ 12 分）
[ ] Step 2：确认冲突形态（一 / 二 / 三 / 四 型）
[ ] Step 3：确定等待窗口三项上限（时间 / 价格 / 动能）
[ ] Step 4：在交易记录本上写下等待开始时间和窗口截止时间
[ ] Step 5：设置价格警报（等待窗口的价格下限和企稳目标位）
```

### 等待窗口运行中（每根 1H K 线收盘检查）

```
[ ] 检查本根 K 线是否触发任一"否定信号"（见第六章）
[ ] 检查是否触发任一等待窗口上限（时间 / 价格 / 动能）
[ ] 更新冲突强度评分（是否发生变化？）
[ ] 判断当前处于三条路径中的哪一条
```

### 触发冲突解除或放弃（决策时刻）

**路径一解除时：**

```
[ ] 1H 企稳打分是否达到对应门槛（弱 70 / 中 75 / 强 80）？
[ ] 首仓比例是否按冲突强度调整（弱 40% / 中 20% / 强 15%）？
[ ] 止损是否按冲突强度对应的系数设置？
[ ] 4H 动能状态是否仍满足入场前提（未超动能上限）？
```

**路径二超时时：**

```
[ ] 记录本次"放弃"的具体原因（哪个上限触发）
[ ] 标记冲突区价格范围（高点和低点）
[ ] 设置价格突破冲突区高点的警报（用于重新入场判断）
```

**路径三转空时：**

```
[ ] 是否满足 ≥ 3/4 路径三识别标准？
[ ] 止损设置为：冲突期间最高价 + ATR × 1.5
[ ] 首仓为标准空单的 50%（4H 未完全确认转空）
[ ] 记录 4H 转空的进展，追踪是否逐步满足系统空头条件
```

## 十、待讨论议题

### 议题 1：等待窗口时间参数的验证

当前方案的等待时间（弱冲突 5 根、中冲突 8 根、强冲突 12 小时）来自对"正常回调节奏"的经验判断，建议通过以下方式验证：

- 回测 BTC 过去 12 个月中所有 4H 多头 + 1H 空头的场景
- 统计从 1H 转空到重新企稳的平均 K 线根数（按冲突强度分层）
- 验证当前时间上限是否覆盖了 80% 以上的正常回调场景

### 议题 2：路径三的启动时机

路径三（转空机会）的识别标准目前设定为"强冲突满足 ≥ 3/4 条件"，但在实际操作中，从做多等待状态切换到做空的心理障碍较大，建议讨论：

- 路径三是否应该作为独立的交易信号，与原系统并行运行？
- 是否应当设定"路径三激活需要专门确认"的机制，避免频繁切换方向？
- 强冲突场景下的路径三首仓（标准的 50%）是否过于保守，或过于激进？

### 议题 3：冲突强度评分的主观性

第二章的冲突强度评分使用 6 个维度打分，部分维度（如"1H MACD 位置"）的边界判断仍有主观成分。建议讨论：

- 是否可以将部分维度替换为完全客观的数值阈值？
- 例如"1H MACD 位置"改为"当前绿柱绝对值 / 历史均值"的具体比例
- 评分表是否需要根据不同的整体市场环境（牛熊）调整各维度权重？

### 议题 4：多个等待窗口并行的管理

实际操作中，可能同时存在多个不同级别的冲突等待窗口（例如正在等待一个中冲突解除，同时新出现了一个弱冲突）。建议讨论：

- 是否允许在同一账户中同时管理多个等待窗口？
- 若多个等待窗口同时触发解除信号，仓位如何分配？
- 是否应当限定每次只处理一个最高优先级的冲突窗口？
